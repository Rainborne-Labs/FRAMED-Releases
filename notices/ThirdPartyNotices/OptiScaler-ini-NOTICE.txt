OptiScaler.ini configuration templates embedded in Framed.Staging.dll

Framed.Staging.dll contains OptiScaler.ini configuration templates. FRAMED writes them, with the setting
values you choose, as OptiScaler.ini into a game folder when you install Neural Rendering. They are not
FRAMED's own work and are not covered by the FRAMED Freeware Licence.

Origin
- OptiScaler NR 0.9.51 (ShyVortex/OptiScaler-DLSSNR-PreSR-Multipass, tag v0.9.51), based on OptiScaler:
  https://github.com/ShyVortex/OptiScaler-DLSSNR-PreSR-Multipass/tree/v0.9.51
  https://github.com/optiscaler/OptiScaler
- Skynizz OptiScaler DLSS 5 1.3.0 (Skynizz/optiscaler-dlss5):
  https://github.com/Skynizz/optiscaler-dlss5

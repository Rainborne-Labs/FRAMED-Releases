NVIDIA RTX device list (Framed.Discovery.dll, embedded as "NvidiaRtxDevices")

Framed.Discovery.dll contains a list of NVIDIA PCI device IDs and GPU chip names taken from pci.ids, the
PCI ID database of the PCI ID Project (https://pci-ids.ucw.cz/), pciutils/pciids version 2026.10.20,
SHA-256 5061033a8c13354302ef9f01e8c439fa5221655aca4132dd85866efc52412634.
FRAMED uses only the entries of vendor 10DE whose name contains RTX.

# FRAMED 0.19.1-alpha.14 — first public alpha

**Pre-release.** Windows 10/11 x64. FRAMED is experimental: it changes files in game folders when you ask it to. Use the modifications offline or in single-player only.

## Install and run
1. Download `FRAMED_0.19.1-alpha.14.zip` below.
2. Optional: check it against `SHA256SUMS.txt`:
   ```powershell
   Get-FileHash .\FRAMED_0.19.1-alpha.14.zip -Algorithm SHA256
   ```
3. Unpack the **whole** ZIP to a folder on a local drive. Do not run FRAMED from inside the ZIP.
4. Start `Framed.exe` and read the risk notice. `FIRST-RUN.txt` explains the first steps (English and Polish).

No installer, no administrator rights and no separate .NET installation are needed. `Framed.exe` is not code-signed, so Windows SmartScreen may warn on first start.

## What this release contains
- Library: finds Steam, Epic and GOG games and folders you add; analyses each game read-only.
- Neural Rendering and Multi-Frame Generation install and uninstall per game, each as one transaction with backups; Settings › Recovery can finish or roll back installations.
- 14 interface languages (Settings › Language).
- Update checks against this repository. FRAMED only tells you that a newer release exists; it never downloads or installs itself. Alpha builds follow pre-releases by default; a channel you saved is kept.
- FRAMED Freeware Licence for FRAMED itself; every third-party licence and notice is in the ZIP (`ThirdPartyNotices`), including the source text of the GPL-3.0 OptiScaler.ini templates FRAMED embeds.

## Limitations
- **Installed is not working:** "Installed" means FRAMED's files are in place. It is not proof that Neural Rendering runs or that MFG presents generated frames; check in the game. FRAMED's own tests use synthetic data and do not run real games.
- NVIDIA GeForce RTX GPUs only. MFG through FRAMED: RTX 40 only. No route for 32-bit games, Direct3D 9/10 or OpenGL. See the README for the full list.
- Games with anti-cheat: modified files can be detected and lead to account penalties, including bans.
- Components (OptiScaler, ReShade, add-ons) are downloaded from their publishers only when you choose them; the NVIDIA NR runtime for the NR Nexus route must already be on your PC.
- Production MultiPass is blocked.
- The 12 languages other than English and Polish are machine-assisted and not reviewed by native speakers; some technical messages stay in English.

## Report a problem
Open an issue: https://github.com/Rainborne-Labs/FRAMED-Releases/issues/new/choose
- **Application bug** — crashes, interface, discovery, installation records, Recovery.
- **NR / FG problem** — Neural Rendering or Frame Generation in a specific game (FRAMED version, GPU, driver, game, renderer EXE, API, method, symptoms).

Remove personal data (for example your Windows user name in paths) from logs before attaching them. FRAMED sends no telemetry.
